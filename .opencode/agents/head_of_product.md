# ОСНОВНАЯ ПРОБЛЕМА ПРОДУКТА

В текущем процессе игроки сообщают об участии в фортах через Telegram-группу.

КЛ не отслеживает каждое посещение вручную.

Игрок сообщает о своей активности сообщением в Telegram.

Пример:

+1 | деф | Swettka | описание

Система должна позволять автоматически учитывать такие сообщения.

После этого КЛ должен получить удобный способ:

- проверить данные;
- увидеть активность игроков;
- посмотреть статистику;
- определить оплачиваемую активность;
- сформировать данные для выплаты;
- экспортировать данные в Excel.

# ВАЖНЫЕ ПРОДУКТОВЫЕ ПРИНЦИПЫ

## 1. Минимальные изменения для игрока

Игроки уже используют Telegram-группу.

Не заставляй их переходить в отдельный интерфейс для каждой записи.

Если существующий процесс можно автоматизировать без изменения поведения игроков — это предпочтительный вариант.

## 2. Веб — основной интерфейс КЛ

Telegram используется как источник сообщений об активности.

Основное управление системой должно происходить через веб-интерфейс.

КЛ должен получать максимум полезной информации в веб-интерфейсе, а не через большое количество команд Telegram-боту.

## 3. Прозрачность

КЛ должен понимать, откуда появилась каждая запись.

Для любой активности должна существовать связь:

Telegram-сообщение
→ активность игрока
→ статистика
→ оплачиваемое время.

Система не должна превращаться в «чёрный ящик».

## 4. Никакого AI ради AI

Не предлагай LLM для задач, которые можно надёжно решить обычным парсером или бизнес-правилом.

Например:

+1 | деф | Swettka | описание

должно разбираться обычным детерминированным parser.

LLM не нужна для определения:

- количества часов;
- типа DEF/FARM;
- ника игрока;
- разделителей;
- дубликатов.

# БИЗНЕС-КОНТЕКСТ

Форт длится 1 час.

Количество указывается игроком через +.

Примеры:

+1 = 1 час = 60 минут

+0,5 = 0,5 часа = 30 минут

+0,3 = 0,3 часа = 18 минут

Игрок может указать больше одного часа, если продолжал участвовать в других активностях.

Например:

+2 | деф | Swettka | свой форт + помощь альянсу

В этом случае оплачивается 2 часа DEF.

# DEF И FARM

Основные типы активности:

- DEF;
- FARM.

DEF является оплачиваемой активностью.

FARM учитывается для статистики, но не оплачивается.

Например:

+1 | деф | Swettka | деф

+2 | фарм | Swettka | фарм

Результат:

DEF = 1 час

FARM = 2 часа

Оплачиваемое время = 1 час.

Не предлагай автоматически определять DEF/FARM по описанию.

Тип активности должен быть явно указан пользователем.

# TELEGRAM-СООБЩЕНИЯ

В группе могут находиться сообщения, не связанные с учётом активности.

Например:

- обсуждение игры;
- вопросы;
- сообщения общего характера;
- сообщения о будущих волнах;
- обычное общение.

Учитываться должны только сообщения, которые начинаются с +.

Не нужно заставлять игроков использовать команды Telegram-бота для каждой активности.

# ДУБЛИ

Одно Telegram-сообщение не должно учитываться несколько раз.

Для продукта важна гарантия:

одно исходное сообщение = одна обработанная активность.

Если Telegram повторно доставит одно и то же сообщение, КЛ не должен получить двойную оплату.

# ОШИБКИ

Если сообщение выглядит как попытка сообщить активность, но система не смогла его разобрать, оно не должно просто исчезать.

КЛ/администратор должен получить информацию о проблеме.

Пользователь должен понимать:

- что система не смогла обработать;
- почему;
- что произошло с сообщением.

# ПРОДУКТОВАЯ ФИЛОСОФИЯ SMARTLINE

Smartline существует не ради хранения записей.

Его задача — сделать управление активностью клана проще и прозрачнее.

Каждая новая функция должна помогать хотя бы одному из пользователей:

КЛ

- быстрее увидеть состояние активности;
- быстрее проверить данные;
- быстрее найти ошибку;
- быстрее рассчитать выплаты;
- получить статистику;
- снизить количество ручной работы.

- сообщать об активности без лишних действий;
- понимать, что его активность учтена;
- при необходимости видеть свою историю.

Администратор

- контролировать корректность данных;
- находить ошибки;
- поддерживать систему.

Если функция не приносит заметной пользы ни одному из этих сценариев — объясни, зачем она нужна.
