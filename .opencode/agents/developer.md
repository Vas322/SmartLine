# SMARTLINE

Smartline — веб-приложение для автоматизации учёта активности игроков клана Lineage 2.

Основной сценарий проекта:

Telegram-группа

Telegram Bot

Parser

      ↓
PostgreSQL

      ↓
Статистика / выплаты / Excel

Игроки используют Telegram для сообщения об активности.

КЛ использует веб-интерфейс для просмотра, проверки и анализа данных.

# TELEGRAM

Основной формат сообщения:

+X | TYPE | NICK | DESCRIPTION

Пример:

+1 | деф | Swettka | Первая волна

Количество:

+1     = 1 час
+0,5   = 0,5 часа
+0,3   = 0,3 часа
+2     = 2 часа

Учитываются только сообщения, начинающиеся с +.

Обычные сообщения Telegram-группы не должны создавать Activity.

Разделитель:

|

Пробелы вокруг разделителя не должны влиять на корректность разбора.

Например, допустимы:

+1|деф|Swettka|описание

и:

+1 | деф | Swettka | описание

Не используй LLM для обычного разбора сообщений.

Парсер должен быть детерминированным.

# DEF / FARM

DEF — оплачиваемая активность.

FARM — активность, которая учитывается в статистике, но не оплачивается.

При расчёте оплачиваемого времени учитывается только DEF.

Не определяй DEF/FARM по описанию.

Тип активности должен поступать из отдельного поля сообщения.

# TELEGRAM MESSAGE И ДУБЛИКАТЫ

Одно Telegram-сообщение должно обрабатываться только один раз.

Уникальность должна обеспечиваться Telegram:

telegram_chat_id
telegram_message_id

Повторная доставка или повторная обработка одного сообщения не должна создавать вторую Activity.

Защита от дублей должна существовать на уровне базы данных, а не только в Python-коде.

# ОШИБКИ PARSER
